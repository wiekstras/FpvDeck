# Repository assets

- `branding/` contains editable identity and social-preview SVG sources.
- `diagrams/` contains rendered architecture SVGs beside editable Mermaid source.
- `renders/` contains explicitly labeled product concepts and their accuracy gate.
- `ui/` contains reproducible captures generated by the Qt/QML simulator.
- `screenshots/` is reserved for measured bench, HIL, and physical-prototype evidence.

Do not place generated build output, unlicensed footage, or vendor artwork here.
