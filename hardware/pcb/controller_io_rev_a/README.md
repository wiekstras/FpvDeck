# Controller-I/O Rev A KiCad project

The KiCad project container exists, but schematic/PCB capture is intentionally
blocked on ADC EVM results, T8L measurements, MCU pin budget, power fault analysis,
and verified manufacturer footprints. An empty project is safer than invented
connectivity. See `TODO.md` and `docs/PROTOTYPES.md` for the release gates.

Planned sheets: power entry/sequencing, MCU/debug, protected balance frontend,
controls, thermal/fan/buzzer, modular T8L/VRX/compute interfaces, and test points.
